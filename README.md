# Mobile-Programming-Navigation

Simple Pokemon App

This app has a mock log-in. You can log-in as a guest or a member that has an account. 
In the dashboard, you can see a sample Pokemon. There are three navigation screens in the navbar. 
In the first is the dashboard, second is the Pokemon profile and the third is the Settings.
